# Ember Bloom — a breathing art card

A 600×800 looping GIF made for an AI agent to send to a person: warm, quiet,
alive. Nothing is imported — every pixel is generated by the script in this
folder (`make_card.py`, numpy + Pillow only).

- **File:** `ember-bloom.gif` — 600×800, 40 frames, 100 ms/frame, 4.0 s loop,
  2.63 MB, 128-colour adaptive palette per frame, Floyd–Steinberg dither.
- **Preview:** `ember-bloom-preview.png` (frame 0).
- **Reproduce:** `python3 make_card.py out.gif preview.png` (deterministic:
  fixed seed 11, same Pillow/numpy versions produce the same bytes;
  SHA-256 of the shipped GIF is `63be3e9c…82c46d`).

## The idea

An ember on a dark night that slowly inhales and exhales. The card is meant to
feel like a small gift, not a banner: a square of deep teal-black at the top,
a cream plate below with just the title and the artist's name.

The picture is six-fold: a rose outline, a ring of amber petals, a hot centre,
a smaller companion ember at lower left, and a slow drift of dust. During one
loop the petals open and close, the centre warms, the outline cools, and the
dust sways a few pixels — one breath every four seconds.

## How the loop is made seamless

Every time-dependent term is a periodic function of `t = 2π·i/N`:

- breath `b = 0.5 − 0.5·cos t` (0 at the seam, 1 mid-loop);
- petals `cos(6θ + 1.30·b)`;
- ribbons `cos(kθ ± t + φ)`;
- motes `θ_k = θ0 + 0.28·s_k·sin(t + θ0)`;
- companion ember `sin/cos(t + 0.8)`.

There is no noise animation, no random position per frame and no linear drift
in phase — the only randomness is seeded once for static grain and mote
placement. The GIF therefore returns exactly to frame 0, and the saved file
loops with `loop=0`.

## Colour and size

Warm light on cold dark, with a paper plate:

- background `#090c11`, haze teal `#366070`, rose `#ec686e`, amber `#ffaa58`,
  cream `#fff0d2`, paper `#f5eee3`, ink `#221c28`;
- the art window is 552×552 with a soft painted shadow on the paper;
- grain is static at 0.0022 (just enough to stop banding) — earlier versions
  with per-pixel animated grain made the GIF 4.7 MB because the noise defeats
  LZW;
- palettes are adaptive per frame (128 colours, Floyd–Steinberg) rather than a
  shared global palette; the global palette version was 9 MB and showed less
  colour fidelity.
